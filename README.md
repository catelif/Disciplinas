# Disciplinas

**Repositório de Conteúdo para Alunos de Telemática**

Este repositório foi criado por alunos da TELEMÁTICA com o objetivo de auxiliar os estudantes do curso, oferecendo acesso a materiais e informações relevantes para o seu aprendizado.  
A intenção é centralizar recursos que possam complementar as aulas, facilitar a compreensão de conceitos e promover o estudo colaborativo.

## Contribuições e Issues

Encorajamos a participação ativa de todos! Para isso, habilitamos as seções de **Issues** e **Pull Requests**. Você pode utilizar essas funcionalidades da seguinte forma:

- **Reportar erros**: Caso encontre alguma informação incorreta ou desatualizada nos materiais, abra uma *Issue* descrevendo o problema.
- **Sugerir melhorias**: Proponha novas ideias de conteúdo, organização ou funcionalidades para o repositório através de uma *Issue*.
- **Fazer perguntas**: Utilize as *Issues* para tirar dúvidas sobre os materiais disponíveis ou sobre o funcionamento do repositório.
- **Compartilhar recursos**: Se você possui algum material que acredita ser útil para outros alunos, pode sugerir sua inclusão abrindo uma *Issue* ou, se já tiver o material pronto e adaptado, enviar diretamente via *Pull Request*.

---

### 📌 O que são *Issues*?

*Issues* são ferramentas de comunicação dentro do GitHub que permitem relatar problemas, sugerir melhorias ou fazer perguntas relacionadas ao repositório.  
Elas funcionam como tópicos de discussão e são ideais para iniciar conversas sobre possíveis mudanças ou correções.

### 🔧 O que são *Pull Requests*?

*Pull Requests* são propostas de alteração no conteúdo do repositório.  
Quando você faz uma modificação em uma cópia do projeto (um *fork*), pode enviar essas mudanças para que sejam analisadas e, se aprovadas, integradas ao repositório principal.

---

Todas as *Issues* e *Pull Requests* serão analisadas pela equipe responsável pelo repositório.  
Avaliaremos a pertinência da solicitação, a qualidade do material (em caso de sugestões) e a viabilidade de implementação.  
Após a análise e aprovação, as alterações ou adições serão realizadas no repositório.

Sinta-se à vontade para contribuir com materiais, sugestões e correções, tornando este espaço ainda mais útil para a comunidade de alunos de Telemática.
